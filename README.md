## Editing the site

No coding required. Open `index.html` in any text editor and search (Ctrl/Cmd+F) for **`EDIT`** — every changeable piece of text is marked. Type new text between the tags without deleting the `< >` tags themselves.

**To add photos:** search for **`PROJECT PHOTO`** (project cards) or **`EDIT YOUR PHOTO`** (portrait), place your image beside `index.html`, and update the `src="..."` filename. Project photo lines are switched off by default — remove the surrounding `<!--` and `-->` to activate one.

Suggested image names: `air-quality.jpg`, `hvi-athens.jpg`, `hri-attica.jpg`, `gee-calculator.jpg`, `bus-routing.jpg`.

## Publishing & updating (GitHub Pages)

The site is hosted free via **GitHub Pages**.

**Update in the browser:**
- Small text edits — open `index.html`, click the ✏️ pencil icon, edit, then **Commit changes**. Live within ~1 minute.
- New photos or larger changes — **Add file → Upload files**, drag in the updated files, then **Commit changes**. Same-named files replace the old ones.

Changes can take up to 10 minutes to appear.
