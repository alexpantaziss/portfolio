# Personal Portfolio - Alexandros Pantazis

This is my personal portfolio website. I'm a Project Manager in EU Funded Programmes (LIFE, EUI, Horizon Europe) with a background in GIS and remote sensing, working on climate resilience and energy transition.

🌐 **Live site:** [alexpantaziss.github.io/portfolio](https://alexpantaziss.github.io/portfolio/)

## What's on the site

- Featured GIS projects: heat vulnerability mapping, school bus routing optimization, a real-time air quality observatory, and more
- Professional experience and EU-funded projects I've managed or contributed to
- Conference presentations, skills, and education
- Contact details

## How it's built

I created it with plain **HTML, CSS, and vanilla JavaScript**. Everything lives in a single `index.html` file, with no frameworks and no build step. It includes a light/dark theme toggle, project filters, scroll-reveal animations, and an animated topographic background on the hero section. Fonts are Poppins and Open Sans via Google Fonts.

The site is hosted for free on **GitHub Pages**, and every commit to `main` goes live within a few minutes.
